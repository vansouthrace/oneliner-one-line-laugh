## About

An entry for the [make.fun](https://make.fun/bounty/u-plucky-finch-20-one-line-one-laugh-0ffe66ea) bounty "One Line, One Laugh": a single funny line, at most 200 characters, funny on its own with no setup. This one turns a bank warning into a personality test.

## Entry

> My bank called to say my account is overdrawn, which was news to me, since I thought overdrawn was just a personality trait.

## How to run

Requires Node 22.18+:

```sh
node main.ts
```

It writes the entry to `/output/entry.txt`.

## Verification

- Entry length: 124 characters (limit: 1-200 characters).
- Single line, plain text, no trailing newline inside the entry.
- The laugh lands on the last words: the financial problem is reframed as a character trait, and the speaker is genuinely unbothered.
